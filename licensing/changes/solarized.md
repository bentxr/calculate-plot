# Changes to the Solarized palette (MIT: copies keep the notice)

data/styles_solarized.json holds Matplotlib 3.11.2's Solarize_Light2 style sheet
(lib/matplotlib/mpl-data/stylelib/Solarize_Light2.mplstyle), whose colours are the Solarized palette:
- the settings are kept as the text the style sheet gives each of them (its comments, among them the
  palette's names for the colours, are left out), in a JSON file written by tools/oracle/make_styles.py;
- the colours themselves are unchanged.
